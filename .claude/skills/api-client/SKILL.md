# API client conventions

## Layers
`screen → hook (TanStack Query) → service (src/api/services/*.ts) → apiClient (src/api/client.ts)`

## Files
- `src/api/generated/schema.ts`: generated by `npm run api:types` (openapi-typescript from `${API_URL}/swagger/v1/swagger.json`). Never edit by hand.
- `src/api/types.ts`: re-exports friendly aliases, e.g. `export type CreateRideRequest = components['schemas']['CreateRideRequest']`.
- `src/api/endpoints.ts`: every path as a constant or function. Example:
  ```ts
  export const ENDPOINTS = {
    auth: { login: '/api/Auth/login', register: '/api/Auth/register' },
    rides: {
      create: '/api/Rides',
      cancelByUser: (rideId: number) => `/api/Rides/${rideId}/cancel-by-user`,
    },
    routes: { estimate: '/api/Routes/estimate' },
    chat: { messages: (rideId: number) => `/api/Chat/rides/${rideId}/messages`, conversations: '/api/Chat/conversations' },
    tripHistory: { user: (userId: number) => `/api/TripHistory/user/${userId}` },
    promo: { user: (userId: number) => `/api/PromoCodes/user/${userId}`, apply: '/api/PromoCodes/apply' },
    users: { byId: (id: number) => `/api/Users/${id}`, update: '/api/Users' },
  } as const;
  ```
- `src/api/client.ts`: a single axios instance with `baseURL` from `src/constants/config.ts` and a 15 s timeout.
  - Request interceptor: adds `Authorization: Bearer ${token}` from the auth store, plus `Accept-Language` from the current i18n language.
  - Response interceptor: on 401, calls `authStore.logout()` once (with a guard against loops), then rejects. Leave a clearly marked `// TODO(refresh)` hook where a refresh call would go.
- `src/api/errors.ts`: `class ApiError { status; code; message; details }` plus `toApiError(unknown)`. It handles axios errors, network/timeout errors, and the `{ success:false, message }` envelope used by Auth and Routes. Hooks and screens only ever see `ApiError`.
- `src/api/services/<domain>.ts`: plain async functions, one per endpoint. They unwrap envelopes and map DTOs to domain types. Example:
  ```ts
  export async function estimateRoute(input: EstimateInput): Promise<RouteEstimate> {
    const { data } = await apiClient.post<RouteEstimateResponse>(ENDPOINTS.routes.estimate, toEstimateRequest(input));
    if (!data.success || !data.data) throw new ApiError({ message: data.message ?? 'estimate_failed' });
    return mapEstimate(data.data);
  }
  ```

## Hooks
- These live in `features/<feature>/hooks/`. Query keys come from `src/constants/queryKeys.ts` (factory style: `queryKeys.tripHistory(userId)`).
- Use `useQuery` / `useInfiniteQuery` for paged lists (`pageNumber`/`pageSize`, stop when `pageNumber >= totalPages`). Use `useMutation` for POSTs.
- Never pass `userId` from props or user input. Read it from `useAuthStore(s => s.user?.id)` inside the hook or service.

## Rules
- Don't use `fetch` directly or create a second axios instance. The only exception is the Google APIs client in `src/lib/google/` (see the maps-location skill).
- Don't call the debug, driver or admin endpoints from this app.
- If you need an endpoint that doesn't exist, don't fake a URL. Write the service against an interface, return a clear "not supported" error or use a mock behind `__DEV__`, and append the request to `docs/BACKEND_REQUESTS.md`.
- After the backend changes Swagger, run `npm run api:types`, then `npx tsc --noEmit`, and fix any drift.
